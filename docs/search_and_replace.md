
Few Plugings which I use for search and replace

## grug-far
- Defaults: local_leader (buffer local keymaps), ripgrep (search engine)
- :GrugFar to open, In visual range mode: it'll prefill the search string with the current visual selection <leader>sr
- :GrugFarWithin `In case you wanna do search and replace within visual selection` In V-Mode <leader>sv
